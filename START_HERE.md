Этот файл предназначен для AI-агента, который умеет читать и изменять файлы открытого проекта в PyCharm, запускать команды в терминале и выполнять тесты.

## 1. Подготовка проекта

1. Создай новую папку проекта, например `ai_product_assistant`.
2. Открой эту папку в PyCharm.
3. Скопируй папку `docs` из этого архива в корень проекта.
4. Скопируй этот файл `START_HERE.md` в корень проекта.
5. Убедись, что в проекте доступен Python 3.12 или новее.
6. Открой AI-агента в PyCharm и предоставь ему доступ к текущему проекту и встроенному терминалу.

> Важно: названия меню и способ подключения агента зависят от версии PyCharm и выбранного AI-инструмента. Используй официальный плагин/интеграцию, доступную для твоей версии IDE.

## 3. Настройка API-ключа

1. Получи API-ключ Gemini в официальном интерфейсе Google AI Studio.
2. После того как агент создаст `.env.example`, попроси его создать локальный `.env` на основе шаблона, если это ещё не сделано.
3. Вставь ключ только в локальный `.env`:

```dotenv
GEMINI_API_KEY=твой_реальный_ключ
GEMINI_MODEL=имя_доступной_модели
```

4. Не отправляй реальный ключ в чат с AI-агентом и не добавляй его в Git.
5. Проверь, что `.env` включён в `.gitignore`.

## 4. Команды для ручного запуска

В терминале PyCharm, из корневой папки проекта:

```bash
python -m venv .venv
```

Активация виртуального окружения:

**Windows PowerShell**
```powershell
.venv\Scripts\Activate.ps1
```

**Windows cmd**
```bat
.venv\Scripts\activate.bat
```

**macOS / Linux**
```bash
source .venv/bin/activate
```

Установка зависимостей и запуск:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
pytest -q
streamlit run app.py
```

Если PyCharm уже создал виртуальное окружение, повторно создавать его не нужно — выбери существующий интерпретатор проекта.
