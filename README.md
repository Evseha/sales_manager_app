# AI Product Assistant

Локальное Streamlit-приложение для подготовки B2B-карточек промышленного оборудования по данным, предоставленным пользователем.

## Принцип достоверности

Приложение не генерирует идеи, характеристики, области применения или числовые значения при отсутствии таких сведений во входных источниках. Неизвестные значения отображаются как `Данных нет`; противоречия отмечаются как `требует проверки`. Значения и единицы измерения не преобразуются.

## Установка и запуск

Используйте Python 3.14.2, уже назначенный проекту PyCharm. В PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Скопируйте `.env.example` в `.env` и укажите только локально:

```dotenv
GEMINI_API_KEY=ваш_ключ
GEMINI_MODEL=имя_доступной_модели
```

`.env` исключён из Git. API-ключ не выводится в интерфейсе и не записывается в логи.

## Возможности

- Ручной ввод, вставка текста, список характеристик и загрузка JSON.
- Извлечение заголовка, meta-description и видимого текста одной публичной URL-страницы.
- Структурированный ответ Gemini с Pydantic-валидацией и программной проверкой характеристик.
- Редактирование полей результата, предупреждения и источники.
- Выгрузка JSON, Markdown и TXT через браузер без записи серверных файлов.

Тестовые шаблоны находятся в `examples/`; они содержат только названия, модели и URL, без неподтверждённых технических данных.
